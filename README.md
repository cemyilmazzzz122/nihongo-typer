# Nihongo Typer

A Raycast extension that converts Romaji into Hiragana and Katakana as you type — no need to switch your keyboard layout.

## Usage

Open the **Convert Romaji to Kana** command and type a word using Latin letters (e.g. `matcha`). The Hiragana result appears at the top (`まっちゃ`) and the Katakana result right below it (`マッチャ`). Press Enter on either result to copy it to the clipboard.

## Privacy

Conversion happens entirely locally. No network requests are made and no data ever leaves your machine.
